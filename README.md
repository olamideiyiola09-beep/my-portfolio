## Getting Started

Clone the repository:

```bash
git clone https://github.com/olamideiyiola09-beep/my-portfolio.git
```

Navigate into the project:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

The portfolio is deployed using Vercel and connected to GitHub for continuous deployment.

Updates pushed to the configured production branch are automatically deployed.
